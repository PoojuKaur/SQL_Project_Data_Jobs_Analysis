# SQL_Project_Data_Jobs_Analysis

# 📊 Data Analyst Job Market Analysis (SQL Project)

## 📌 Introduction

This project explores the data analyst job market. It focuses on:

* 💰 Top-paying jobs
* 🔥 Most in-demand skills
* 📈 Skills that lead to higher salaries

The goal is to help understand what skills are important to become a successful data analyst.

---

## 📖 Background

I created this project to better understand:

* Which data analyst jobs pay the most
* What skills companies are looking for
* How to choose the best skills to learn

This project makes it easier for others to plan their career in data analytics.

---

## ❓ Questions Answered

1. What are the top-paying data analyst jobs?

3. What skills are most in demand?

## 📊 The Analysis

### 1. 💰 Top Paying Jobs

* The highest salaries range from **$184,000 to $650,000**
* Many companies offer high salaries (e.g., tech and finance companies)
* Job titles vary from **Data Analyst to Director roles**

👉 This shows there is strong earning potential in this field.

---

### 2. 🧠 Skills for Top Paying Jobs

Most common skills in high-paying jobs:

* SQL
* Python
* Tableau
* R
* Excel

👉 SQL is the most important skill for top salaries.

---

### 3. 🔥 Most In-Demand Skills

Top 5 most requested skills:

* Python
* Tableau
* Power BI

👉 These are essential skills for getting a job.
